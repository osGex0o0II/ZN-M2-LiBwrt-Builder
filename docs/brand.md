# 品牌规范

## 名称

产品名固定写作 **ZN-M2 No WIFI**。

- `No WIFI` 不翻译，不添加括号解释。
- 正文可以用“纯有线”描述形态，但不把它作为名称后缀。
- 构建线名称仍为 `ZN-M2 <上游> <内核> <加速>`，例如 `ZN-M2 LiBwrt 6.12 NSS`。

## 标志

主标志是 **Terminal Z**：暖白圆角方形底上，用三条几何笔画构成蓝色 Z，右下角留一个短缺口，作为终端光标的克制暗示。

- 不旋转、不拉伸、不改变笔画比例。
- 不加渐变、阴影、发光或第二种强调色。
- 浅色背景使用 `mark.svg` / `logo.svg`；深色背景使用 `mark-dark.svg` / `logo-dark.svg`。
- 最小使用尺寸为 24 px；小于 32 px 时使用 `favicon.svg` 的简化 Z。

品牌蓝只用于强调和关键动作，不铺满大面积背景。

## 字体

- 标志字标使用 `Inter`，回退 `Segoe UI`、`Arial`、sans-serif。
- 文档正文使用系统无衬线字体，保持可读性优先。
- 不引入装饰字体；需要精确排版时，将字标转为轮廓。

## 语气

- 少形容词，多事实：写清版本、边界、验证状态和失败方式。
- 不写“最强”“完美”“零问题”等无法验证的结论。
- 不承诺未验证的内存容量或设备兼容性。
- 不把上游组件说成自研；明确区分“上游能力”和“本项目集成”。
- 发布说明区分“构建完成”和“真机验收完成”。

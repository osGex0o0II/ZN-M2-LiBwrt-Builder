# 文档索引

本仓库文档分为两类。

## 用户文档

- [README.md](../README.md)：固件介绍、刷机、首次登录、默认配置、常见问题和许可说明。

## 维护者文档

- [维护者说明](maintainers.md)：构建、版本固定、自动更新、缓存和发布流程。
- [多上游维护说明](multi-upstream.md)：独立 profile、硬件适配、软件保留与构建验收。
- [历史设计记录](history/)：2026 年 7 月至 10 月的工程设计与实施计划，用于追溯当时的决策。
  - 这些文档面向维护者，不是用户操作指南。
  - 文中可能包含旧路径、旧变体（例如已移除的 1G 版本）和内部技术术语。
  - 历史记录保留英文原文，便于对照当时的提交、测试和上下文。
  - 当前目录结构、构建方式和功能说明，以根目录 README 为准。

## 许可证

- [LICENSE](../LICENSE)：本仓库的 MIT 许可证。
- [NOTICE.md](../NOTICE.md)：固件中第三方组件的许可说明。

## 文档维护原则

- 用户文档使用简洁、直白的中文，避免内部代号和不必要的实现细节。
- 维护者文档可以保留技术细节，但应说明适用范围和历史背景。
- 许可证正文不做改写；如需补充说明，单独写入 NOTICE.md。

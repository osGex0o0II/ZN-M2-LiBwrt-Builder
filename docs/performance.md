# 性能与内存测试

本页保留项目此前记录的真机观察结果，仅供故障排查与版本选择参考。部分数据缺少完整日志、流量拓扑及复现实验环境，**不构成跨版本性能排名**。

## 历史结果

| 指标 | ImmortalWrt 6.18 NSS | ImmortalWrt 6.18 PPE |
|:---|---:|---:|
| CoreMark（4 线程总分） | 19,278（另一次首启 20,477） | 未记录 |
| 空载可用内存 | 62–68 MB | 105 MB |
| 跑分温度 | 37.5 °C | 未记录 |

这些数据来自特定设备、固件及测试时点，未提供统一的测试条件。CoreMark 是 CPU 基准测试，不能直接代表 NAT、PPPoE 或代理吞吐量。

此前 PPE 构建线还记录：

- 4 路并发 NAT 下载，总吞吐量约 300 Mbps：开启硬件分载后设备 CPU 占用约 0.1%，关闭时约 8.3%。
- 连续运行 31 小时，未观察到 OOM 或内核 panic。
- 500 个并发 LAN 下载请求完成；16 线程负载时记录的最高温度为 49.4 °C。

上述结果不能外推到其他线路、规则集、代理流量或固件版本。

## NSS 与 PPE 的内存差异

历史采样值：

| 指标 | 6.18 NSS | 6.18 PPE |
|:---|---:|---:|
| `MemTotal` | 199,008 kB | 214,520 kB |
| 记录的内核预留 | 64,096 kB | 48,584 kB |
| 不可回收 Slab | 约 42.7 MB | 约 21.7 MB |
| `VmallocUsed` | 约 12.2 MB | 约 6.5 MB |
| 匿名页 | 约 4.5 MB | 约 4.5 MB |

`/proc/meminfo` 中的 `kB` 通常按二进制千字节解释。Slab 与 Vmalloc 的指标含义不同，**不能直接相加并当作独立的物理内存占用**。

NSS 需要固件预留区、驱动缓冲及连接状态。PPE 不加载 NSS 固件，历史空载样本显示其可用内存更多；差额随内核、驱动和工作负载变化。

ZRAM 将交换页面压缩存放于 RAM，并非不占物理内存。压缩比、CPU 开销和实际节省量取决于页面内容。

## 转发与代理的区别

- **NSS + ECM**：对符合条件的连接使用 Qualcomm NSS 转发路径。
- **PPE + EDMA**：使用流量分载及相关硬件；需通过现场计数器验证是否命中。
- **FWX / Shortcut-FE**：遵循对应上游的快速转发实现，不等同于 NSS 硬件分载。
- **HomeProxy / sing-box**：代理处理通常需要 CPU 和用户态参与，不能以直连转发结果代表代理性能。

硬件分载可能影响部分依赖逐包处理的 QoS、计数和防火墙扩展规则。若需要逐连接管控，应在实际流量下验证规则是否生效；必要时关闭分载。

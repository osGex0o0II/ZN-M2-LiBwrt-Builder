- `autoreboot.@schedule[0].enabled=0`; the configured 02:00 schedule is disabled.

- Boot log reports `zn-m2-healthcheck: restart dnsmasq` followed by `lan dhcp remains unavailable after dnsmasq restart`. This is a separate LAN DHCP health-check warning; it does not itself run a whole-device reboot and does not explain the missing WAN delegated IPv6 prefix.

## Comparison Notes

LAN router advertisements are configured as `hybrid`, so RA is not simply disabled. The observed blocker for client IPv6 is that WAN6 has no delegated prefix and LAN has no assigned prefix. The `dhcpv6=relay` and `ndp=relay` values should be compared after the firmware change, along with WAN6 PD and LAN prefix assignment.

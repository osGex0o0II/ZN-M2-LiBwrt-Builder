# 常见问题

## 为什么没有 Wi-Fi？

ZN-M2 No WIFI 面向纯有线路由场景。镜像不编入 Wi-Fi 驱动与固件，也不提供“关闭无线”的软开关；USB 功能同样不编入。

## 支持哪些内存容量？

最低要求为原厂 256 MB 内存的 ZN-M2。1 GB 扩容机型已在真机验证；其他扩容容量以设备实际识别为准。扩容机型不会因为镜像名称中的历史 `256M` 标识而受限。

## 为什么系统显示的内存少于标称？

内核、加速栈、保留区和固件会占用一部分物理内存。系统可见内存低于标称容量是正常现象，不代表内存故障。

## HomeProxy / sing-box 能使用 NSS、PPE 或 FWX 加速吗？

不能。硬件加速针对符合条件的转发连接；代理流量仍由 CPU 处理。代理吞吐应单独测量，不能用直连转发数据代替。

## 从另一条构建线升级后，地址为什么变了？

跨构建线升级不保留配置。不同线的默认管理地址、接口命名或服务配置可能不同；升级前先备份，升级后按 [安装与恢复](installation.md) 重新配置。

## 刷入后无法启动怎么办？

先确认设备确为 ZN-M2、内存满足最低要求、NAND 分区布局与目标引导程序匹配。首次刷机使用 `factory.ubi`，已在 OpenWrt 上运行时使用 `sysupgrade.bin`。仍无法启动时按安装文档进入恢复流程。

## 应该选哪条构建线？

按数据平面、界面偏好和代理需求选择，详见 [构建线说明](build-lines.md)。如果不确定，优先选择长期维护的 LiBwrt 6.12 NSS 或 ImmortalWrt 6.18 PPE。
